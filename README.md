# Weather App

A responsive Weather App built using HTML, CSS, and JavaScript.

## Features
- Search weather by city
- Current location weather
- 5-day weather forecast
- Responsive glassmorphism UI
- Dynamic weather icons
- Error handling
- Loading animation
